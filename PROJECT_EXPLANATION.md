# Vishnu Creations: Project Explanation

## 1. Project Overview
This project is a comprehensive **Attendance, Employee, and Order Management System** custom-built for **Vishnu Creations** (a premium leather manufacturing company). It serves as a centralized internal portal to manage the company's daily operations, staff attendance, manufacturing orders, and client communications.

## 2. Key Features

### 🏢 Employee & Attendance Management
- **Role-Based Access Control:** Separate dashboards and permissions for ADMIN, MANAGER, and EMPLOYEE roles.
- **Secure Check-In System:** Employees can check in and out using a secure, time-sensitive 6-digit OTP token generated by the Admin/Manager.
- **Live Attendance Tracking:** Admins can view live attendance status (Present, Absent, Late) in real-time.
- **Leave Management:** Employees can request leaves, which Admins/Managers can approve or reject.

### 📦 Order & Production Management
- **Order Tracking:** Track custom leather manufacturing orders from "Order Received" to "Delivered".
- **Progress Tracking:** Visual progress bars indicating the manufacturing stage (Design, Cutting, Stitching, Finishing, etc.).
- **Cloud Image Gallery:** Production images (Sample, Production, Finished) can be uploaded securely to **Cloudinary** and attached to specific orders.
- **Dynamic Dashboard:** A dashboard for Admins that summarizes active orders, delayed orders, live staff attendance, and recent enquiries.

### 📧 Notifications & Communication
- **System Notifications:** In-app notification bell to alert users of new leave requests or status updates.
- **Password Reset:** Secure OTP-based forgot password flow that emails the employee directly using NodeMailer/SMTP.

## 3. Technology Stack

### Frontend (User Interface)
- **Framework:** React.js powered by Vite for blazing fast performance.
- **Styling:** Tailwind CSS for a beautiful, responsive, and modern design.
- **Icons & Animations:** Lucide-React for crisp icons and Framer Motion for smooth, premium animations.
- **Routing:** React Router DOM for navigating between pages.

### Backend (Server & API)
- **Framework:** Spring Boot (Java) providing a robust, enterprise-grade REST API.
- **Security:** Spring Security with JSON Web Tokens (JWT) to ensure only authorized users can access sensitive company data.
- **Database:** H2 Database (currently configured for development/file-based storage), completely mapped using Spring Data JPA (Hibernate).
- **File Storage:** Cloudinary integration for handling high-quality image uploads without bloating the local server.
- **Email Services:** JavaMailSender for dispatching OTPs and automated emails.

## 4. How the Systems Connect
1. **The User** opens the React Frontend in their browser.
2. The Frontend sends HTTP requests using **Axios** to the Spring Boot Backend (running on `localhost:8080`).
3. The **Backend** verifies the user's JWT Token for security.
4. The Backend fetches or updates data in the **Database**.
5. If the user uploads a photo (e.g., an order sample), the Backend sends that photo directly to **Cloudinary** and saves the returned Image URL in the Database.
6. The Backend sends the requested data back to the Frontend, which smoothly updates the screen for the User.
